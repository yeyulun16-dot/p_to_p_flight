# 点到点飞行试飞检查表

## 0. 每次通电前

- [ ] 机架、桨叶、桨帽、电机、起落架无松动和裂纹
- [ ] 电池电压、遥控器电量正常
- [ ] 桨叶区域无人，急停/锁桨动作已明确
- [ ] A→B 空域无人员、线缆和障碍物
- [ ] 参数文件已备份，B 点方向和距离已经复核

## 1. 拆桨测试

- [ ] 飞控固件编译、下载成功
- [ ] `/scan` 持续发布
- [ ] `/laser_array/ground_height` 与实际高度方向一致
- [ ] `ros2 run tf2_ros tf2_echo map laser_link` 连续、无跳变
- [ ] `/target_position` 单位为 cm
- [ ] `/target_velocity` 静止目标附近收敛到 0
- [ ] 机体转动后，map→body 速度转换方向正确
- [ ] 停止 PID 后 0.30 秒内串口桥发送零速度并关闭转发
- [ ] 冻结测高或 `map → laser_link` TF 后，PID 先发布零速度，串口桥随后关闭转发
- [ ] 拔掉上位机串口后 0.30 秒内飞控 `m_speed_*` 归零
- [ ] 遥控器可随时接管/停止任务
- [ ] CH6 保持低位时调用 `start`，飞控不会解锁或执行速度
- [ ] 收到 `0x67 enable` 后只有 CH6 拨到高位才进入原切模式/解锁流程
- [ ] 未收到 `0x67 enable` 时，上电保持 CH6 高位不会启动；必须先确认低位再拨高，才进入原机兼容启动流程
- [ ] CH6 拨回低位、速度超时或收到 `0x67 disable` 后外部速度目标归零

## 2. 低风险系留测试

配置建议：`cruise_height_cm=60`、`b_offset_x_cm=50`、`b_offset_y_cm=50`、`terminal_behavior=hold`（横向正值为机体左侧）。

- [ ] 只验证垂直起飞，XY 目标保持 A
- [ ] 到 60 cm 后高度误差稳定，无持续振荡
- [ ] 上升和下降速度均不超过 `max_vertical_velocity`
- [ ] 前飞 50 cm 的方向正确
- [ ] 到 B 后持续悬停，不停止控制输出
- [ ] 调用 `/p_to_p/abort_hold` 后保持当前位置
- [ ] 不在空中调用 `/p_to_p/stop_output`

## 3. 正式距离

- [ ] 每次只增加一个变量：距离、速度或高度
- [ ] 记录 A/B 实际误差、最大超调、飞行时间和电池电压
- [ ] XY PID 先调 P，再少量 D；无充分证据不启用 I
- [ ] 高度 PID 与测高滤波分别调试
- [ ] 连续三次 `hold` 模式通过后才测试 `land`

## 4. 下降测试

- [ ] `landing_height_cm` 对应实际可安全接地的传感器读数
- [ ] 下方障碍检测工作，障碍触发后恢复到巡航高度
- [ ] 到近地高度后调用 `stop_output`，再人工锁桨
- [ ] 断开/冻结测高或定位时，`stop_output` 会拒绝执行
- [ ] 明确记录：当前版本没有视觉精准降落和自动锁桨
